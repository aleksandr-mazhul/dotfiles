# Zellij — шпаргалка

Открывается прямо из zellij: `Ctrl+b ?` (закрыть: `q`).

## Главное за 30 секунд

- Всё как в tmux: `Ctrl+b`, затем буква. `Ctrl+a` тоже работает.
- Передумал после `Ctrl+b`? Нажми любую свободную клавишу или `Esc`: префикс сбросится.
- Рамки появляются, только когда во вкладке больше одной панели: активная — персиковая, остальные приглушённые. После `Ctrl+b` рамка меняет цвет: префикс нажат.
- `SCROLL: 0/35` в углу рамки — счётчик истории: ты на `0` строк от низа, выше ещё 35. Растёт, когда листаешь.
- Справа в баре горит пилюля режима: TMUX, SCROLL, SEARCH, RENAME. Нет пилюли — обычный ввод.
- `Super+H/J/K/L` переходит между панелями и сплитами nvim как одним целым.
- Всё сохраняется само. После перезагрузки открой kitty: вкладки, панели, `claude --continue` и `npm run …` вернутся.

## Панели

| Клавиши | Что делает | tmux |
| --- | --- | --- |
| `Ctrl+b \|` | Сплит вправо | то же |
| `Ctrl+b -` | Сплит вниз | то же |
| `Ctrl+b h j k l` | Фокус влево / вниз / вверх / вправо | то же |
| `Super+H/J/K/L` | То же без префикса, сквозь сплиты nvim | vim-tmux-navigator |
| `Ctrl+b o` | Следующая панель | то же |
| `Ctrl+b ;` | Предыдущая (последняя активная) панель | то же |
| `Ctrl+b {` / `}` | Поменять панель местами с соседней | то же |
| `Ctrl+b ← → ↑ ↓` | Ресайз; дальше просто стрелки, пока не нажмёшь `Esc` | `bind -r` |
| `Ctrl+b f` или `z` | Развернуть панель на весь таб и обратно | zoom |
| `Ctrl+b Space` | Следующая раскладка: вертикальная → горизонтальная → стопка | next-layout |
| `Ctrl+b !` | Вынести панель в отдельную вкладку | break-pane |
| `Ctrl+b x` | Закрыть панель (сразу, без вопроса) | kill-pane |

## Вкладки

| Клавиши | Что делает | tmux |
| --- | --- | --- |
| `Ctrl+b c` | Новая вкладка | новое окно |
| `Ctrl+PgDn / Ctrl+PgUp` | Следующая / предыдущая | prefix+n / p |
| `Ctrl+Shift+]` / `[` | То же (мышь: боковые кнопки через kanata) | то же |
| `Ctrl+Shift+→ / ←` | То же | то же |
| `Ctrl+b Tab` | Прыгнуть на прошлую вкладку и обратно | ≈ last-window |
| `Ctrl+b H` / `L` | Сдвинуть вкладку влево / вправо | swap-window |
| `Ctrl+Shift+H / L` | То же без префикса | то же |
| `Ctrl+b $` | Переименовать: печатай, `Enter` сохранить, `Esc` отмена | rename-window |
| `Ctrl+b &` | Закрыть вкладку (спросит `y/N`) | kill-window |

Имя вкладки само следует за командой: `nvim`, `claude`, `npm`, а в простое `fish`, как automatic-rename в tmux. Если переименовать вкладку вручную, имя останется твоим.

## Сессии

| Клавиши | Что делает |
| --- | --- |
| `Ctrl+b s`, `w`, `C` | Менеджер сессий: переключиться, создать новую |
| `↑` / `↓`, `Enter` | Внутри менеджера: выбрать сессию (подсвечена) и подключиться |
| `Ctrl+r` | Внутри менеджера: переименовать сессию |
| `Ctrl+b Ctrl+r` | Список завершённых сессий, чтобы воскресить |
| `Ctrl+b d` | Отключиться; сессия продолжает жить |
| `Ctrl+b Ctrl+s` | «Сохранить»: zellij и так пишет состояние каждые 10 секунд |

## Прокрутка, поиск, копирование

**Копирование как в tmux:** `Ctrl+b v` открывает всю историю панели в nvim: `v` выделить, `y` скопировать в буфер, `:q` назад.

Просто листать: `Ctrl+b [`, сразу страница вверх — `Ctrl+b PgUp`. Колесо мыши тоже листает.

| Клавиши | Что делает |
| --- | --- |
| `j` / `k`, `↓` / `↑` | Строка вниз / вверх |
| `Ctrl+e` / `Ctrl+y` | Тоже по строке, как в vim |
| `Ctrl+d` / `Ctrl+u` | Полстраницы |
| `Ctrl+f` / `PgDn`, `PgUp` | Страница |
| `g` / `G` | В самое начало / в самый конец |
| `{` / `}` | Прыжок к предыдущему / следующему приглашению шелла |
| `/` или `?` | Поиск: печатай, `Enter`, дальше `n` / `N` |
| `e` | Открыть всю историю в nvim, а там `v…y`, `/`, что угодно |
| `y` | Скопировать выделенное мышью |
| `Esc`, `q`, `Enter` | Выйти (вернуться вниз) |
| `Ctrl+PgDn / Ctrl+PgUp` | Сразу на другую вкладку |

Копирование: выдели мышью, и текст уже в буфере. С клавиатуры — `Ctrl+b v` (история в nvim, там `v…y`).
Бонус: `Ctrl+b y` копирует в буфер вывод последней команды целиком.

## Плавающие панели и прочие фишки

| Клавиши | Что делает |
| --- | --- |
| `Ctrl+b g` | Показать или спрятать слой плавающих панелей (если пусто, откроет шелл) |
| `Ctrl+b e` | Открепить текущую панель в плавающую / вернуть на место |
| `Ctrl+b S` | Синхронный ввод во все панели вкладки; ещё раз — выключить |
| `Ctrl+b t` | Часы (peaclock), `q` закрыть |
| `Ctrl+b ?` | Эта шпаргалка |
| `Ctrl+b Ctrl+b` | Отправить программе настоящий `Ctrl+b` (`Ctrl+a Ctrl+a` для `Ctrl+a`) |

Мышь: клик выбирает панель, перетаскивание границы меняет размер, колесо листает, выделение копирует.

## Из командной строки

``fish
zellij ls                        # сессии (живые и завершённые)
zellij attach имя                # подключиться / воскресить
zellij kill-session имя          # убить живую сессию
zellij delete-session имя        # забыть завершённую
zellij run -f -- htop            # команда в плавающей панели
zellij run -- npm run dev        # команда в новой панели
zellij edit файл                 # открыть файл в $EDITOR в новой панели
zellij action rename-tab имя     # любое действие из шпаргалки — скриптом
``

## tmux ↔ zellij

- Новые окна kitty открываются в zellij, если задано `set -Ux MUX zellij`. Вернуть tmux: `set -Ue MUX`.
- Окно вообще без мультиплексора: `Ctrl+Alt+N` в kitty.
- В одной сессии держи что-то одно: tmux внутри zellij (или наоборот) спорит за `Ctrl+b`.

## Чем отличается от tmux (честно)

- `Ctrl+b x` закрывает панель сразу, без вопроса.
- Нет клавиатурного выделения в режиме прокрутки, поэтому `Ctrl+b v` открывает историю в nvim.
- Вкладку переименовывает `Ctrl+b $` (в tmux это `,`); сессию — в менеджере `Ctrl+b s`, `Ctrl+r`.
- `Ctrl+b %` и `Ctrl+b "` не делают сплит (в tmux ты их тоже отвязал): используй `|` и `-`.
- Нет командной строки tmux (`Ctrl+b :`); её роль играет `zellij action …`.

## Если что-то не так

- Бар пустой или плагин спрашивает разрешение: `zellij-plugins-fetch`, потом перезапусти zellij.
- Застрял в каком-то режиме: `Esc`, в крайнем случае `Ctrl+b Esc`.
- Цвета съехали после смены обоев: `theme-render` перерисует бар и тему, zellij подхватит сам.
